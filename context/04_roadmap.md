## Phase 1 - Local-only MVP, no backend (done 2026-07-13)

Usable and offline from day one. All state lives in IndexedDB; no backend is touched.
- **Local store** ([src/db/dexie.ts](../frontend-react/src/db/dexie.ts)): `operations` table (the log, PK `opId`, indexes on `groupId`/`[groupId+lamport]`/`lamport`/`synced`) + `meta` (deviceId, lamport). `bumpLamport` (atomic tick) and `ingestOps` (idempotent bulkPut + advance clock past ingested ops).
- **Op layer** ([src/sync/ops.ts](../frontend-react/src/sync/ops.ts)): createGroup/renameGroup/deleteGroup, addMember/renameMember/removeMember, addExpense/updateExpense/deleteExpense. Each appends one op in an rw transaction.
- **Fold engine** ([src/sync/fold.ts](../frontend-react/src/sync/fold.ts)): pure `foldOps(ops)` -> AppState. Sorts by (lamport, opId), dedupes opIds, LWW per field, delete is terminal, orphan update/delete dropped. This is the convergence guarantee.
- **Domain math** ([src/domain/](../frontend-react/src/domain/)): `split.ts` (integer cents, deterministic remainder, always conserves the total), `balances.ts` (nets to zero), `simplify-debts.ts` (greedy min-cash-flow, <= n-1 transfers, deterministic).
- **UI**: hooks `useGroups`/`useGroupData` via `dexie-react-hooks` useLiveQuery; pages Groups (list/create), GroupDetail (participants, Depenses/Soldes tabs, delete, settle-up), AddExpense (amount parse, payer, equal-split chips). French, mobile-first.
- **Tests: 53 passing** across split/balances/simplify/format/fold/ops/scenario. Includes the resilience set: idempotent replay, 200 random-permutation convergence, LWW + tie-break, delete-beats-edit, orphan ops, rapid concurrent appends (unique lamports), durability across DB reopen, two-device offline merge.
- Verified: `tsc -b` clean, `vite build` emits the service worker, dev server boots and transforms all modules with no errors. Not yet driven by click-through in a real browser (no browser driver in this environment); the data pipeline behind every screen is covered by the scenario tests.
- Status: **complete**.

## Phase 2 - Backend + sync (done 2026-07-13)

Two devices/people now converge through the self-hosted relay.
- **Backend** ([app/api/v1/endpoints/](../backend/app/api/v1/endpoints/)): `POST /groups/register` (idempotent, mints a share code), `GET /groups/resolve/{code}`, `GET /groups/{id}`, `POST /groups/{id}/ops` (idempotent push, dedup by opId), `GET /groups/{id}/ops?since=` (pull by seq cursor). Services `group_service` (share codes from an unambiguous alphabet) + `sync_service`. The server is a pure relay: stores and serves ops, never merges.
- **Schema**: `created_at` stored as BigInteger ms (client wall clock); `seq` is `BigInteger().with_variant(Integer, "sqlite")` so SQLite tests autoincrement. Fresh migration `c2dc57cd3548`.
- **Frontend**: sync client ([sync/client.ts](../frontend-react/src/sync/client.ts), wire = Operation minus `synced`), sync engine ([sync/engine.ts](../frontend-react/src/sync/engine.ts): push unsynced -> mark synced -> pull since cursor -> ingest), Dexie v2 `syncState` table (cursor + shareCode per shared group), `use-sync` hook (mount/online/visibility/30s interval), share dialog + join-by-code + invite link (`/?join=CODE`), offline SyncBar.
- **Tests**: 13 backend pytest + 6 frontend engine tests (two-device convergence over a faithful mock server, offline queue survives + pushes on reconnect, idempotent repeated sync, local-only groups never sync). Total FE 59.
- Verified live: `docker compose up`, curl register/resolve/push/idempotent-repush/pull round-trip the wire format; CORS allows the :3060 origin. Not click-tested in a browser (no driver here).
- Status: **complete**.

## Resilience pass: "bulletproof homelab" (done 2026-07-14, strengthened 2026-08-12 and 2026-08-13)

See decisions D29, D39 and D41. Sync self-heals after any server-side data loss (404 wipe or cursor rewind after a restore-from-backup): the devices re-register and re-seed the full log automatically, now guarded by a database-generation UUID so a recreated server's overtaken cursor can never skip history (D39). Requests time out at 15s (no more wedged sync engine), pushes are batched (500 ops) under a raised nginx body limit, PWA updates prompt instead of force-reloading, an invite-link join interrupted by the password gate retries automatically, "Regler" is double-tap-proof, dates are local-timezone (not UTC), `/health` returns 503 on DB outage. New features: JSON import by replay (home menu, money payloads validated as numbers since D41) and "Quitter le groupe (cet appareil)" for shared groups. QR invites (D39/D40) join on fresh load and same-tab navigation, erasing credentials from the address bar both ways. 174 FE + 45 backend tests.

## What makes this simpler than Tricount

- One-tap equal split as the default; advanced splits are opt-in.
- Balances + a single "who pays whom" list, nothing else on the main screen.
- No ads, no account wall, no upsell.
- Instant, offline, yours.
